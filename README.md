# KNN识别手写数字
AI project

## 1.项目来源：

    本人在学习knn算法和交叉验证网格搜索时所做的案例😄

## 2.项目作用：

### 2.1模型功能：

    传入28*28像素手写数字，可以用训练出的大模型预测出手写数字的数值，其中还用了交叉验证和网格搜索用来优化超参数选择和模型选择。🍎

### 2.1全部函数：

    show_num():拿到数据并将Series对象转化为Numpy数组，将数组重塑之后进一步转化为图像用到了plt.imshow()函数进行绘制

    train_model():将数据合理划分之后给模型进行训练

    gridsearch_cv():用交叉验证和网格搜索的方式进行最佳超参数选择和最佳模型选择

    test_model():用来测试模型

## 3.项目制作遇到的困难：

    将png图片转化为numpy数组时，图片有多个维度，容易导致Series对象出现错误；:
    
    我通过将前3个通道进行求平均值然后忽略第4通道（Alpha）将照片重塑为符合模型的numpy数组。
